# Changelog

All notable changes to WebOsz will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2025-09-27

### Added
- Initial release of WebOsz
- Support for loading .osz files
- 4-key osu!mania gameplay
- Customizable scroll speed and playback rate
- Score tracking and results screen
- Custom keybinds and note colors
- Particle background and visual effects

### Features
- Score, combo and accuracy tracking
- Detailed post-game results
- Customizable keybinds
- Customizable note colors
- Responsive design for various screen sizes
